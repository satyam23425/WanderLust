# 🌍 WanderLust – Full Stack Airbnb Clone

WanderLust is a full-stack Airbnb-inspired web application where users can explore, create, edit, and manage property listings. The project focuses on authentication, CRUD operations, cloud image storage, responsive UI, and full-stack development concepts.

---

# 🚀 Features

* 🔐 User Authentication & Authorization
* 🏠 Create, Edit, Delete Listings
* 📸 Upload Property Images
* 💬 Flash Messages & Form Validation
* 🌐 Responsive UI using Bootstrap
* 🗂 MongoDB Database Integration
* ☁ Cloudinary Image Storage
* 🛡 Secure Session Handling
* 📍 Location-based Listings
* ✨ Clean and User-Friendly Interface

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/satyam23425/WanderLust.git
```

## 2️⃣ Move into Project Folder

```bash
cd WanderLust
```

## 3️⃣ Install Dependencies

```bash
npm install
```

## 4️⃣ Create Environment Variables

Create a `.env` file and add:

```env
CLOUD_NAME=your_cloud_name
CLOUD_API_KEY=your_api_key
CLOUD_API_SECRET=your_api_secret
DB_URL=your_mongodb_url
SECRET=your_secret_key
```

---

# ▶️ Run the Project

```bash
node app.js
```

OR

```bash
npm start
```
